# صفحة كشف الحساب الإلكتروني

صفحة ثابتة واحدة لكل المحلات تعرض الكشف الذي في الرابط نفسه (بعد `#`).
لا تحمل بيانات ولا تتصل بأي سيرفر؛ الفك في متصفح الزبون.

## النشر على GitHub Pages (مرة واحدة)

1. مستودع عام باسم `kashf` على حساب GitHub (`orgh1`).
2. ارفع محتوى هذا المجلد كما هو إلى جذر المستودع:
   `index.html`، `kashf.js`، `app.js`، `style.css`.
3. Settings ← Pages ← Source: `Deploy from a branch` ← الفرع `main` والمجلد `/ (root)`.
4. الصفحة تصير على `https://orgh1.github.io/kashf/` — وهو `kStatementPageUrl`
   في `lib/services/statement_link.dart`. اسم آخر = غيّر الثابت وابنِ البرنامج.

فعّل التحقق بخطوتين على حساب GitHub: من يغيّر هذه الصفحة يرى كل كشف يُفتح بعده.

## صيغة الرابط

`<الصفحة>#1.<المفتاح>.<المشفَّر>` — base64url بلا `=`.

- المفتاح: AES-128، عشوائي لكل رابط.
- المشفَّر: nonce (12) + AES-GCM(zlib(JSON)) + وسم (16).
- JSON: `v` النسخة، `s` المحل، `sp` جواله، `n` الزبون، `c` العملة، `b` الرصيد
  (بالأغورات)، `k` مورّد، `d` تاريخ الكشف، `x` عدد كل الحركات إن قُصّت،
  `l` الحركات `[تاريخ، بيان، مدين، دائن، رصيد]`، `p` طرق الدفع `[اسم، رقم، صاحبه]`.

الاختبار `test/statement_link_test.dart` يبني الرابط في Dart ويفكّه بـ`kashf.js` نفسه في Node.
